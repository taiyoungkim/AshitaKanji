### 근거 (ASO Scout, 2026-10-07)

- `오니칸` — Title, 1위. **유지** (변경안도 Title 맨 앞에 그대로 둠).
- `일본어를` — Subtitle, 184위 / `외우고` — Subtitle, 43위. "Title로 이동" 권고.
  - 둘 다 인기도 5(Apple 최저값)이고 조사·어미가 붙은 형태라, 그대로 옮기지 않고 실제 검색어(`JLPT`, `일본어`, `한자`, `단어장`, `외우기`)로 대체.
- Title이 30자 중 3자만 사용 → 핵심 검색어를 Title로 이동.

### 작성 규칙

- 키워드 필드는 쉼표 구분, 공백 없음. Title·Subtitle에 이미 있는 단어는 넣지 않는다 (Apple이 필드 간 단어를 조합해 색인).
- 앱에 없는 기능의 키워드(회화, 가타카나 학습 등)는 넣지 않는다 — 심사 2.3.7 리젝 사유.
- 적용 후 2~4주 순위를 관찰하고, 반응 없는 키워드는 교체한다.

## 적용 절차

1. App Store Connect → 오니칸 → 다음 버전(현재 저장소 기준 `1.0.2`)의 "제출 준비 중" 페이지를 연다.
   - 버전이 없으면 좌측 iOS 앱 옆 `+`로 새 버전을 만든다.
2. **앱 정보**(좌측 메뉴, 버전 페이지가 아님)에서 이름·부제를 변경안으로 수정 → 저장.
3. 버전 페이지의 **키워드** 필드에 변경안 키워드 입력 → 저장.
4. 해당 버전 빌드를 선택해 심사 제출. 승인·출시 시점에 새 메타데이터가 반영된다.
