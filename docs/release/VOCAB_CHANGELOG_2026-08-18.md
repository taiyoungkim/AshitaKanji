근거: `data/track-a/kanji_format_normalization_2026-08-18.json`.
전수 감사에서 발견한 19자의 형식 경고 28건을 정리했다.

- 쉼표 때문에 괄호와 문맥이 여러 뜻으로 잘못 분리된 9자: 기본 의미로 정규화

## 11. TTS 작업자가 보면 되는 한 줄 요약

1. 단어 TTS는 이미 활성 6,638개 전부 있다. 다시 뽑지 않는다.
2. 예문 TTS는 **39개만** 새로 뽑는다. ID·문장은 §6.1 또는 `tts_followup_2026-08-18.json`.
3. 사전 재검수 3건은 이미 새 예문 오디오가 있다. `--force`로 덮지 말 것.
4. 제거한 `な`형 49개 파일은 쓰지 말고 보관/삭제. 어간으로 복사 금지.
5. 끝나면 `npm run audio:prepare` → `npm run tts:audit:examples`.
6. 재생 경로는 그대로다. 파일명 = `word.id`. 맵은 gitignore (`src/lib/audio/audioMap.gen*.ts`).
