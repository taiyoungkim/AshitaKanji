# Visual regression artifacts

`baseline/` is changed only by `npm run ui:approve`. `actual/` is generated by the
capture build, while `overlay/` and `diff/` are generated by `npm run ui:diff`.
The immutable visual source is Onikan commit `fa259e7`, `handoff/redesign-2026-08/final-screens/`.

```sh
EXPO_PUBLIC_UI_CAPTURE=1 npx expo run:ios --configuration Release --device "AshitaKanji UI iPhone"
npm run ui:capture -- --platform=ios
npm run ui:approve -- --from-design
npm run ui:diff
```

Capture mode requires a compile-time flag and a private app-container marker. It has no control in production UI.
